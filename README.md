# oneiros-coda-dev

Oneiros Coda Dev is the dev arm of Oneiros Coda Marketing Team. Repos here are independent product and client work.

## Repositories

| name | what it is | status |
| --- | --- | --- |
| zarevia-edge | B2C grocery commerce platform for the UK. Storefront, subscriptions, courier tracking, payments. | active |
| oclabs-webapp | Marketing site for the Oneiros Coda studio. | maintained |
| shaju-thomas | Client webapp for Shaju Thomas. Delivered. | archived |
| navaneeth-decor-webapp | Webapp for Navaneeth Home Decor, a 23-year-old family interiors business in Palakkad, Kerala. Next.js 14, Tailwind, Framer Motion. Delivered. | archived |

## Build / run

- `zarevia-edge` — Next.js. `npm install && npm run dev`.
- `oclabs-webapp` — Next.js. `npm install && npm run dev`.
- `shaju-thomas`, `navaneeth-decor-webapp` — built per their own READMEs. No further maintenance.

## Status

`zarevia-edge` is live and maintained. `oclabs-webapp` is maintained. The two client webapps were delivered and are not maintained by us post-handover.
